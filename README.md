# AsyncAPITools

AsyncAPITools builds tools for working with AsyncAPI.

The project complements the tools provided by the AsyncAPI Initiative by exploring capabilities that are not yet available there, or that have limited support for a particular programming language, framework, or ecosystem.

## Available Tools

| Tool | Description |
| --- | --- |
| [parser-java-wrapper](https://github.com/AsyncAPITools/parser-java-wrapper) | A Java wrapper around the official AsyncAPI JavaScript parser. |
| [parser-java](https://github.com/AsyncAPITools/parser-java) | A native Java parser for AsyncAPI documents. |

## Roadmap

Planned tools and libraries include:

- **Java generator** for generating code from AsyncAPI documents.
- **Java converter** for converting between supported AsyncAPI formats or versions.
- **Core Java library** to provide reusable foundations for building other AsyncAPI tools.

The roadmap is exploratory and may evolve as the project and AsyncAPI ecosystem grow.
